Vext provides mathematical proof that a communications feed has not been tampered with.
Any client can independently verify that a channel's messages are:

1. **Chronological** — messages appear in timestamp order, not algorithmically sorted
2. **Complete** — no messages have been hidden, deleted, or suppressed
3. **Uninjected** — no advertisements or synthetic content have been inserted
4. **Attributable** — each message's authorship is cryptographically verified

== How it works

Each message in a Vext-verified feed carries a *verification header* containing:

* A BLAKE3 hash of (body + author + timestamp)
* A hash chain link to the previous message (proving ordering)
* A server signature (Ed25519, proving the server attests to this ordering)

Clients can verify the chain independently. If any message is modified, inserted, or
removed, the hash chain breaks and the client can detect it.
